PingPong is my version for the game "Pong" of Atari.

The purpose of the game:
One day I was bored and I decided to develop a tiny game to play with my girlfriend without the use of AI in order to practice C++ and OpenGL, there was no real meaning, just was curious how fun could it be.
The first product was a game for 2 players, one player controlled a ball and the other controlled a paddel\racket, if the ball crossed the paddel's line, then the first player got a point, and if the paddle managed to stop the ball, then player 2 got a point:
https://github.com/user-attachments/assets/0c938caf-1d5e-4800-bd07-a9937de45910

Later I understood that the game was too static and boring, it was challanging and fun in some way, but wasn't exciting much, so I decided to upgrade it to the Pong game we know and love:
